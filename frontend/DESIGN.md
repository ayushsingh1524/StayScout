# StayScout Design System

StayScout is a warm, trustworthy hotel-search experience: inspiring enough for travel discovery, restrained enough for premium clarity, and clear enough for comparison.

## Original blend

- Travel discovery: destination-first search, welcoming imagery, soft rounded controls.
- Premium clarity: generous whitespace, concise copy, quiet surfaces, deliberate hierarchy.
- Decision support: visible prices, ratings, filter chips, and plain-language trust signals.

## Color tokens

| Token | Value | Use |
|---|---|---|
| Ink | `#17202A` | Primary text, dark actions |
| Paper | `#FFFCF7` | Page background |
| Surface | `#FFFFFF` | Cards and dialogs |
| Coral | `#E85D4A` | Primary CTA |
| Coral dark | `#B83C2F` | CTA hover |
| Spruce | `#0D4A42` | Trust and admin accent |
| Mint | `#DDF3E8` | Soft trust surfaces |
| Violet | `#6657D9` | Focus rings |
| Sand | `#F3ECE2` | Secondary surfaces |
| Line | `#E7DED2` | Borders |

Use coral for one primary action in each visual region. Keep public pages warm and spacious, and admin pages information-led. Every touch target is at least 44px with visible keyboard focus.
